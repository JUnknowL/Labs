## Чему равно значение `Test::b` и почему?

1.  ```cpp
    enum Test
    {
        a = 1,
        b = 2,
    };
    ```

2.  ```cpp
    enum Test
    {
        a = 1,
        b,
    };
    ```

3.  ```cpp
    enum Test
    {
        a,
        b,
    };
    ```

4.  ```cpp
    enum Test
    {
        a = -1,
        b,
    };
    ```

5.  ```cpp
    enum Test
    {
        a = (5 + 10 * 5) / 5,
        b,
    };
    ```

6.  ```cpp
    enum Test
    {
        other = 5,
        a = other + 6,
        b,
    };
    ```

7.  Запишите ответ как целое число и как символ.

    ```cpp
    enum Test
    {
        a = '5',
        b = '7',
    };
    ```

8.  Запишите ответ как целое число и как символ.

    ```cpp
    enum Test
    {
        a = '5',
        b,
    };
    ```

9.  Запишите ответ как целое число и как символ.

    ```cpp
    enum Test
    {
        a = 'b',
        b,
    };
    ```

10.  Запишите ответ как целое число.

    ```cpp
    enum Test
    {
        a = 'a' + '1',
        b,
    };
    ```


## Почему?

1. b == 2 так как мы присвоили ему такое значение.
2. b == а+1 == 2 так как она идёт после а которая равна одному.
3. b == 1 так как она идёт после а. А а равно нулю так как это первое число в enum.
4. b == a+1 == 0 так как а == -1.
5. b == a+1 == 12 так как (5 + 10 * 5) / 5 == 11.
6. b == a+1 == 12 так как а == 5+6 == 11.
7. b == 'l' или же 108 так как по таблице ascii '5' == 53, '7' == 55 а 53+55 = 108 что по таблице ascii == 'l'.
8. b == '6' или же 54 так как по таблице ascii '5' == 53 и 54 == '6'.
9. b == 'c' или же 99 так как по таблице ascii 'b' == 98 и 99 == 'c'.
10. b == a+1 == 147 так как '1' == 49 и 'a' == 97 то a == 146.
